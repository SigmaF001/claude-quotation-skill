# น้องคิว (Q) — Claude Code Skill สร้างใบเสนอราคา

AI ผู้ช่วยสร้างและแก้ไขใบเสนอราคาสำหรับฟรีแลนซ์และธุรกิจขนาดเล็ก-กลาง ทำงานผ่าน Claude Code โดยตรง

## ตัวอย่าง Output

```
📋 สรุปใบเสนอราคา QT-2026-004
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ลูกค้า: คุณภูริพัตร จันทร์สว่าง
วันที่: 18 พฤษภาคม 2569 | ใช้ได้ถึง: 17 มิถุนายน 2569

รายการ:
  1. ออกแบบ UI/UX   — 1 งาน × 5,000   = 5,000.00
  2. พัฒนา Frontend — 1 งาน × 8,000   = 8,000.00
  3. พัฒนา Backend  — 1 งาน × 10,000  = 10,000.00

ยอดรวม:    23,000.00 บาท
VAT 7%:     1,610.00 บาท
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ยอดสุทธิ:  24,610.00 บาท
```

สร้างไฟล์ออกมา 3 รูปแบบ:
- **`.xlsx`** — มีสูตรคำนวณ แก้ตัวเลขได้ใน Excel
- **`.docx`** — ปรับดีไซน์ได้ใน Word
- **`.html`** — เปิดในเบราว์เซอร์แล้วกด `Ctrl+P` บันทึกเป็น PDF

---

## ความสามารถหลัก

- **สร้างใบเสนอราคา** ผ่านบทสนทนา — ไม่ต้องเปิด Excel เอง
- **Rate Card** — บันทึกราคามาตรฐานและเสนออัตโนมัติครั้งถัดไป
- **ฐานข้อมูลลูกค้า** — จำข้อมูลลูกค้าเพื่อไม่ต้องพิมพ์ซ้ำ
- **VAT และส่วนลด** — คำนวณทั้งส่วนลดรายการและส่วนลดรวม
- **Edit Mode** — แก้ไขราคา รายการ ลูกค้า หรือตั้งค่าได้ทุกอย่างหลังสร้าง
- **เลขที่ต่อเนื่อง** — QT-[YYYY]-[NNN] ไม่ซ้ำกันทุก session
- **ตั้งค่าครั้งเดียว** — ข้อมูลบริษัท/ฟรีแลนซ์บันทึกใน config ใช้ได้ตลอด

## การติดตั้ง

### ต้องการ
- [Claude Code](https://claude.ai/code) (CLI หรือ Desktop App)
- Python 3.8+ (สำหรับสร้าง Excel และ Word)

### ติดตั้ง Skill

```bash
npx skills add SigmaF001/create-quotation -g -y
```

หรือติดตั้งแบบ manual:

```bash
# สร้างโฟลเดอร์
mkdir -p ~/.claude/skills/create-quotation

# copy SKILL.md
curl -o ~/.claude/skills/create-quotation/SKILL.md \
  https://raw.githubusercontent.com/SigmaF001/create-quotation/main/SKILL.md
```

### ติดตั้ง Python Packages

```bash
pip install openpyxl python-docx
```

### สร้างโฟลเดอร์เก็บไฟล์

สร้างโฟลเดอร์ `Quotation` ที่ต้องการเก็บไฟล์ใบเสนอราคา แล้วแก้ path ใน `SKILL.md` ให้ตรงกับของคุณ

> **Default path:** `E:\Quotation\` (Windows) — แก้ได้ในไฟล์ SKILL.md

## วิธีใช้งาน

### สร้างใบเสนอราคาใหม่

พิมพ์ใน Claude Code:

```
/create-quotation สร้างใบเสนอราคา
```

น้องคิวจะถามข้อมูลทีละขั้น:
1. ข้อมูลลูกค้า (หรือเลือกจากฐานข้อมูล)
2. หัวข้องานและรายการ
3. VAT และส่วนลด
4. ยืนยัน summary ก่อนสร้าง

### แก้ไขใบเสนอราคา / ตั้งค่า

```
/create-quotation แก้ไขราคา item 2 เป็น 50,000
/create-quotation เพิ่ม rate card: ทำ SEO ราคา 12,000 ต่อเดือน
/create-quotation เปลี่ยน VAT เป็น 0%
/create-quotation แก้เบอร์โทรบริษัทเป็น 02-999-8888
```

## โหมดแก้ไข (Edit Mode)

| โหมด | ตัวอย่างคำสั่ง |
|------|--------------|
| แก้ใบเสนอราคา | "เพิ่มส่วนลดรวม 10%", "ลบรายการที่ 3" |
| จัดการ Rate Card | "เพิ่ม rate ใหม่: บริหารโปรเจกต์ 15,000/เดือน" |
| จัดการลูกค้า | "แก้ที่อยู่ลูกค้า XYZ เป็น สุขุมวิท" |
| แก้ข้อมูลบริษัท | "เปลี่ยนเลขบัญชีเป็น 000-1-23456-7" |
| แก้ค่า Default | "เปลี่ยนวันหมดอายุ default เป็น 45 วัน" |

ทุกการแก้ไขจะแสดง **ค่าเดิม → ค่าใหม่** ให้ยืนยันก่อนเสมอ

## ไฟล์ที่สร้าง

| ไฟล์ | หน้าที่ |
|------|---------|
| `quotation_config.json` | ข้อมูลบริษัท, rate card, ลูกค้า, ค่า default |
| `ใบเสนอราคา QT-YYYY-NNN.xlsx` | Excel พร้อมสูตรคำนวณ |
| `ใบเสนอราคา QT-YYYY-NNN.docx` | Word สำหรับปรับดีไซน์ |
| `ใบเสนอราคา QT-YYYY-NNN.html` | HTML สำหรับพิมพ์เป็น PDF |

## ปรับแต่ง

แก้ไขข้อมูลที่ `quotation_config.json`:

```json
{
  "company_info": {
    "type": "freelance",
    "name": "ชื่อของคุณ",
    "phone": "0xxxxxxxxx",
    "email": "your@email.com",
    "address": "ที่อยู่ของคุณ"
  },
  "payment_info": {
    "bank": "ธนาคาร",
    "account_number": "เลขบัญชี",
    "account_name": "ชื่อบัญชี"
  },
  "defaults": {
    "vat": 7.0,
    "valid_days": 30,
    "payment_terms": "ชำระภายใน 30 วัน"
  }
}
```
