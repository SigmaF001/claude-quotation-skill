## ความสามารถหลัก

- **สร้างใบเสนอราคา + ใบเสร็จรับเงิน** ผ่านบทสนทนา — ไม่ต้องเปิด Excel เอง
- **ใบเสนอราคามืออาชีพ** — โลโก้, รหัสสินค้า, VAT แยกสัดส่วน (คิด/ยกเว้น), เงื่อนไขการค้า (เครดิต/มัดจำ/กำหนดส่งมอบ), ช่องลงนามฝ่ายขาย + ยืนยันสั่งซื้อ (ตราประทับ), ตัวอักษรไทย
- **เลขที่ฟอร์แมต** `QT2026XXXX` + **Expiry Alert** เตือนใบเสนอราคาใกล้หมดอายุ
- **ใบเสร็จถูกต้องตามกฎหมายไทย** — เลขผู้เสียภาษี 13 หลัก, สำนักงานใหญ่/สาขา, "ใบเสร็จรับเงิน/ใบกำกับภาษี" อัตโนมัติเมื่อจด VAT
- **หัก ณ ที่จ่าย (Withholding Tax)** — รองรับ 1% / 3% / 5% คำนวณยอดสุทธิที่รับจริง
- **จำนวนเงินเป็นตัวอักษรไทย** — แปลงอัตโนมัติ เช่น "สองหมื่นสี่พันหกร้อยสิบบาทถ้วน"
- **ช่องลงนามผู้รับเงิน** + รูปแบบการชำระ (เงินสด / โอนเงิน / เช็ค)
- **Rate Card** — บันทึกราคามาตรฐานและเสนออัตโนมัติครั้งถัดไป
- **ฐานข้อมูลลูกค้า** — จำข้อมูลลูกค้าเพื่อไม่ต้องพิมพ์ซ้ำ (ใช้ร่วมกันทั้ง 2 เอกสาร)
- **VAT และส่วนลด** — คำนวณทั้งส่วนลดรายการและส่วนลดรวม
- **Edit Mode** — แก้ไขราคา รายการ ลูกค้า หรือตั้งค่าได้ทุกอย่างหลังสร้าง
- **เลขที่ต่อเนื่อง** — QT[YYYY][NNNN] / RE-[YYYY]-[NNN] ไม่ซ้ำกันทุก session
- **ตั้งค่าครั้งเดียว** — ข้อมูลบริษัท/ฟรีแลนซ์บันทึกใน config ใช้ได้ตลอด

## การติดตั้ง

### ต้องการ
- [Claude Code](https://claude.ai/code) (CLI หรือ Desktop App)
- Python 3.8+ (สำหรับสร้าง Excel และ Word)

### ติดตั้ง Skill

```bash
npx skills add SigmaF001/claude-quotation-skill -g -y
```

หรือติดตั้งแบบ manual:

```bash
# สร้างโฟลเดอร์
mkdir -p ~/.claude/skills/claude-quotation-skill

# copy SKILL.md
curl -o ~/.claude/skills/claude-quotation-skill/SKILL.md \
  https://raw.githubusercontent.com/SigmaF001/claude-quotation-skill/main/SKILL.md
```

### ติดตั้ง Python Packages

```bash
pip install openpyxl python-docx
```

### สร้างโฟลเดอร์เก็บไฟล์

สร้างโฟลเดอร์ `Quotation` ที่ต้องการเก็บไฟล์ใบเสนอราคา แล้วแก้ path ใน `SKILL.md` ให้ตรงกับของคุณ

> **Default path:** `E:\Quotation\` (Windows) — แก้ได้ในไฟล์ SKILL.md

## วิธีใช้งาน

### สร้างใบเสนอราคาใหม่

พิมพ์ใน Claude Code:

```
/create-quotation สร้างใบเสนอราคา
```

น้องคิวจะถามข้อมูลทีละขั้น:
1. ข้อมูลลูกค้า (หรือเลือกจากฐานข้อมูล)
2. หัวข้องานและรายการ
3. VAT และส่วนลด
4. ยืนยัน summary ก่อนสร้าง

### ออกใบเสร็จรับเงิน

```
/create-quotation ออกใบเสร็จรับเงิน
/create-quotation ออกใบเสร็จจากใบเสนอราคา QT20260004
```

น้องคิวจะถาม: ผู้ซื้อ → รายการที่รับชำระ → VAT / หัก ณ ที่จ่าย → รูปแบบการชำระ (เงินสด/โอน/เช็ค) → ยืนยัน แล้วออกไฟล์ `.xlsx / .docx / .html` พร้อมจำนวนเงินเป็นตัวอักษรไทยและช่องลงนามผู้รับเงิน

### แก้ไขใบเสนอราคา / ตั้งค่า

```
/create-quotation แก้ไขราคา item 2 เป็น 50,000
/create-quotation เพิ่ม rate card: ทำ SEO ราคา 12,000 ต่อเดือน
/create-quotation เปลี่ยน VAT เป็น 0%
/create-quotation แก้เบอร์โทรบริษัทเป็น 02-999-8888
```

## โหมดแก้ไข (Edit Mode)

| โหมด | ตัวอย่างคำสั่ง |
|------|--------------|
| แก้ใบเสนอราคา | "เพิ่มส่วนลดรวม 10%", "ลบรายการที่ 3" |
| แก้ใบเสร็จรับเงิน | "เปลี่ยนหัก ณ ที่จ่ายเป็น 3%", "เปลี่ยนวิธีชำระเป็นเงินสด" |
| จัดการ Rate Card | "เพิ่ม rate ใหม่: บริหารโปรเจกต์ 15,000/เดือน" |
| จัดการลูกค้า | "แก้ที่อยู่ลูกค้า XYZ เป็น สุขุมวิท" |
| แก้ข้อมูลบริษัท | "เปลี่ยนเลขบัญชีเป็น 000-1-23456-7", "จด VAT แล้ว สำนักงานใหญ่" |
| แก้ค่า Default | "เปลี่ยนวันหมดอายุ default เป็น 45 วัน" |

ทุกการแก้ไขจะแสดง **ค่าเดิม → ค่าใหม่** ให้ยืนยันก่อนเสมอ

## ไฟล์ที่สร้าง

| ไฟล์ | หน้าที่ |
|------|---------|
| `quotation_config.json` | ข้อมูลบริษัท, rate card, ลูกค้า, ค่า default (ใช้ร่วมกันทั้ง 2 เอกสาร) |
| `ใบเสนอราคา QTYYYYNNNN.xlsx/.docx/.html` | ใบเสนอราคา 3 รูปแบบ |
| `quotations_log.json` | log เอกสารสำหรับ Expiry Alert (วันหมดอายุ/สถานะ) |
| `ใบเสร็จรับเงิน RE-YYYY-NNN.xlsx/.docx/.html` | ใบเสร็จรับเงิน 3 รูปแบบ |
